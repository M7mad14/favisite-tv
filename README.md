# Favisite TV

شاشة رئيسية لتلفزيونات Android TV وGoogle TV، مربوطة بحسابك في [فافيسايت](https://favisite.lovable.app).

هذا المستودع للتنزيل فقط: فيه الإصدارات، والكود مو هنا.

## التنزيل

آخر نسخة دائماً على هذا الرابط:

```
https://github.com/M7mad14/favisite-tv/releases/latest/download/favisite-tv.apk
```

كل الإصدارات وملاحظاتها في [Releases](https://github.com/M7mad14/favisite-tv/releases). كل إصدار مكتوب في ملاحظاته بصمة `sha256` للملف.
